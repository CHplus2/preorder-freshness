# Natural voice replacement

The original offline Flite voice has been replaced with Kokoro v1.0 af_heart, a warmer stock neural voice. Narration was lightly rewritten for a conversational delivery, with matching captions. The application footage and the two-minute timeline are unchanged.

Demo_120s_Natural_Voice.mp4 and the current Demo_120s_Narrated.mp4 contain the updated narration. The main showcase ZIP has also been refreshed. Natural_Voice_Preview.mp3 is a short sample of this voice; Bright_Voice_Preview.mp3 is an alternative af_bella sample.

Neither voice is the author, the client, or a claimed exact TikTok voice. For a specific TikTok/CapCut voice, use the voice officially available in that app. No third-party editing account was connected here.

The speech was generated locally using the Apache-2.0-licensed Kokoro model distributed by [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models). Model weights are not included in the download or application repository. Stock synthetic narration is not evidence of a person's participation or endorsement.
