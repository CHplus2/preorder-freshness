The lecturer’s final poster instructions have not yet been issued. The poster is prepared for FYP2, but is not claimed officially approved or guaranteed to earn particular marks. The senior example cannot be positively identified as FYP2 from the supplied image. Its “Expected Results” wording resembles proposal-stage work; its content is only a comparison, not a required template.

The new version retains the green/cream design and five original objectives, adds a short scope statement and one simplified current preorder sequence, and explains the stock-deduction test in plain language. The earlier “200 → 199” meant that a local example order deducted one salad bowl from a starting balance of 200; it was not a user-survey result or real stock claim.

No former i-CATS logo is used. An unlabelled area of about 67 × 67 mm is reserved at the top right for the approved new university logo.

The ZIP contains the editable poster, optional text sections, nine current report diagram sets (PNG, SVG and editable .drawio), eight source screenshots, the original objective text and a checklist for the lecturer’s later instructions. Download it now; editing these ordinary files in PowerPoint, Canva or diagrams.net does not need an active Codex subscription. Check fonts and layout after importing into a different editor.
