## Evidence and its limits

The completed testing evidence retains the recorded 1,049 passing PostgreSQL-backed backend tests with no skips, plus separately recorded frontend/browser and affected UI regression checks. Counts from separate runs are not combined. This revision did not rerun application tests because it changes documents only. It changed no application behaviour, inventory rule, prediction model, trained artifact or deployment setting.

Unit, integration and end-to-end describe the scope of a test. Automated or manual describes how it was executed. The report identifies its recorded checks as automated and does not imply an independent manual tester or completed client survey. Software tests do not establish satisfaction, conversion, profit, food safety or business effectiveness.

The supplied senior report is used as a structural reference, not as evidence for this project's results. The supplied briefing contains partial rubric excerpts, including verifiable validation and a note to link survey questions to objectives. It does not establish a requirement or prohibition on automated testing, nor a fixed sample size. The report is not a guarantee of a mark or full compliance with instructions not yet supplied.

## Current system description

COD requires cash collection or an alternative agreed with the customer before dispatch; tracking does not switch the payment method.
