In Word, select the existing picture → Picture Format → Change Picture → From a File, then choose its numbered PNG. Preserve the existing caption, centre the image, lock its aspect ratio and keep it within the text margins. Use the full-resolution PNG rather than a screenshot of Screenshot_Preview.pdf. Avoid Word’s image compression if it makes labels hard to read. Check the exported PDF afterwards for page breaks and readable text.

Readability matters more than matching one particular laptop. Use the normal viewport for context, and the additional view when a feature needs more space. A full-page screenshot is legitimate, but a very long image can become unreadable on an A4 report page.
