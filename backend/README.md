# Dapur Kita backend

Django REST API for the single-vendor preorder application.

Start with the maintained [root README](../README.md), [deployment guide](../DEPLOYMENT.md),
[preparation scheduling guide](../docs/PREPARATION-PLANNING.md) and
[operations/status guide](../docs/OPERATIONS-AND-FEATURE-STATUS.md).

The root README contains local commands and isolated test instructions. The backend .env may
connect to production Supabase: do not run experiments, resets or test data imports against it.
Older TokenFresh screenshots and payment descriptions are historical, not a current feature specification.
